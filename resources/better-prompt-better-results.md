### Content creation

| Say this instead | Don't say |
|---|---|
| Make sure my client understands it in 5 seconds | Make it more professional |
| Improve it using 3 criteria: clarity, pacing, and CTA | Improve it |
| Summarize it in 3 sentences without losing the main point | Make it shorter |
| Write it the way I speak, without jargon | Make it sound natural |
| Write a post for [client] with a hook in line 1 | Write a post about ... |
| Give me 5 Reel ideas with the hook and format | I need content ideas |
| Fix spelling and rhythm without changing my style | Fix this |
| Make it more persuasive using this real objection: [x] | Make it more persuasive |
| Give me 3 versions and tell me which one you recommend | Write me a caption |

### Thinking and analysis

| Say this instead | Don't say |
|---|---|
| Act as a [specific role] | Explain it to me |
| Analyze this through psychology, strategy, and positioning | Give me information about ... |
| Give me non-obvious angles | What is it? |
| I want a non-generic answer | Make me a summary |
| Write it for someone who already knows the basics | Content ideas |
| Break this concept down | Strategies for ... |
| Challenge this idea | Tips for ... |
| Improve this without softening it | Examples |
| Give me the version nobody dares to say | Benefits of ... |
